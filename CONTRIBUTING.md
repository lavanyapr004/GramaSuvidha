# Contributing to Grama-Suvidha

Thank you for your interest in contributing to **Grama-Suvidha**! We welcome contributions from the community to help improve transparency and accountability in rural development.

## 🤝 How Can I Contribute?

### Reporting Bugs
- If you find a bug, please open an issue on GitHub.
- Include details about your device, Android version, and steps to reproduce the bug.

### Suggesting Features
- We're always looking for ways to improve citizen engagement! 
- Please open an issue with the "feature request" tag to discuss your ideas.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Ensure your code follows the existing Kotlin style.
4. Submit a pull request with a clear description of your changes.

## 🛠 Development Environment
- **IDE**: Android Studio Ladybug+
- **Minimum SDK**: 24
- **Language**: Kotlin 2.0+

## 📜 Code of Conduct
Please be respectful and professional in all interactions within this project.
